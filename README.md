# 🎮 Четыре в ряд (Connect Four)

Классическая настольная игра, реализованная на **Kotlin** в консоли.  
Игроки по очереди бросают фишки в вертикальную доску —  
побеждает тот, кто первым выстроит **4 фишки подряд**  
по горизонтали, вертикали или диагонали.

---

## 🧩 Возможности

- 🔢 Настраиваемое поле (от **5×5** до **9×9**)  
- 👥 Два игрока (имена вводятся при старте)  
- 🎲 Пошаговый режим  
- 🧠 Автоматическая проверка победы  
- 🧱 Отображение доски в консоли  
- 🚫 Проверка корректности ввода  

---
